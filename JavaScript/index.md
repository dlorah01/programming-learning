# JavaScript Mastery Curriculum

A complete rebuild of JavaScript from engine internals to senior-level system thinking — 12 chapters, an answer key, and an interactive drill. Start at Chapter 1 if you're going straight through, or jump to the roadmap for how everything connects.

## Start here

- [Roadmap & index](00-roadmap.html) — how all 12 chapters connect, and the one-sentence version of the whole curriculum

## Chapters

1. [Foundations](01-foundations.html) — history, ECMAScript, engines, parsing, JIT, execution model
2. [Language Fundamentals](02-language-fundamentals.html) — scope, hoisting, TDZ, types, coercion
3. [Functions](03-functions.html) — closures, `this`, `bind`/`call`/`apply`, HOFs, currying
4. [Objects & Prototypes](04-objects-and-prototypes.html) — property descriptors, the prototype chain, Proxy/Reflect
5. [Classes](05-classes.html) — constructor functions, ES6 classes, inheritance, private fields
6. [Asynchronous JavaScript](06-async-javascript.html) — the event loop, Promises, async/await, generators
7. [Memory](07-memory.html) — stack vs. heap, garbage collection, leaks, WeakMap/WeakSet
8. [Modules](08-modules.html) — CommonJS vs. ES Modules, dynamic imports, tree shaking
9. [Error Handling](09-error-handling.html) — try/catch/finally, custom errors, async error propagation
10. [Advanced / Metaprogramming](10-advanced-metaprogramming.html) — Symbols, iterators, Proxy/Reflect, decorators
11. [Performance](11-performance.html) — debounce/throttle, memoization, lazy loading, Big O in practice
12. [Modern JS & Interview Synthesis](12-modern-js-and-interview-synthesis.html) — capstone: feature tour, cross-topic scenarios, the integrated roadmap

## Practice

- [Exercise & answer key](13-exercises-answer-key.html) — every exercise from every chapter, with full mechanism-level explanations
- [Mechanism drill](14-mechanism-drill.html) — interactive quiz with fresh, unseen scenario questions

## How to use this

Read a chapter, attempt its exercises closed-book, then check the answer key — not the other way around. See the roadmap page for how the chapters causally connect to each other, and revisit it whenever a new piece of JS behavior seems "weird" — it almost certainly traces back to one of the mechanisms already covered.
