# Python Mastery Course — Answer Key: Modules 0–18

**The worked answers now live inside each module file**, in an **Exercise Solutions** section directly below that module's exercises. Keeping them next to the questions means there is only one copy to maintain, so the answers can't drift out of sync with the exercises.

Use them the way the course recommends: attempt each exercise cold first, then check your reasoning — and keep your own one-line note on anything you got wrong, since that personal log is the highest-value review material as you go.

Every answer has been re-derived and checked against the question as written and against Python's documented behaviour.
