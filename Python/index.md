# Python Mastery Course

A complete, university-level Python course built for an experienced JS/TS engineer moving into Python — covering language internals, idiomatic style, performance/memory, concurrency, typing, testing, and production engineering, with senior-level interview prep woven through every module.

Start with the **[Roadmap](00_roadmap.html)** for how the modules connect to each other, or jump straight into [Module 0](01_foundations.html).

## Suggested Path

1. Read the **[Roadmap](00_roadmap.html)** first — it explains why the modules are sequenced the way they are.
2. Work Modules 1 → 19 in order, attempting each module's exercises cold before reading its **Exercise Solutions** section further down the same page.
3. Use **[Module 20](20_interview_sprint.html)** for spaced-repetition review — revisit it repeatedly, not once.
